# Onake Imomoh — Cybersecurity Portfolio

Personal portfolio website for Onake Imomoh, focused on SOC analysis, defensive security, detection engineering and incident response.

## Live site

https://onakeimomoh.github.io

## Structure

- About and professional positioning
- Evidence-led capabilities and working toolkit
- Four selected SOC and defensive-security case studies
- Experience and training
- Public CV, verified UBI portfolio dossier and reference letter
- Google Cybersecurity Professional Certificate
- Detailed performance record available on request
- Contact links

The site is a dependency-free static build using semantic HTML, responsive CSS and lightweight JavaScript. It is designed for GitHub Pages and includes reduced-motion and keyboard-accessibility support.
